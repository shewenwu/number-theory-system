数论核心概念

1. 最大公约数 (GCD) 与 最小公倍数 (LCM)
一、求 GCD 与 LCM 的三大武器

1. 质因数分解法（最直观的视角）
基于算术基本定理，将两数分解质因数后，GCD 取各质因数指数的最小值（取交集），LCM 取最大值（取并集）。
例如：\(12 = 2^2 \times 3^1\)，\(18 = 2^1 \times 3^2\)。
\(\gcd(12, 18) = 2^{\min(2,1)} \times 3^{\min(1,2)} = 2^1 \times 3^1 = 6\)。
\(\text{lcm}(12, 18) = 2^{\max(2,1)} \times 3^{\max(1,2)} = 2^2 \times 3^2 = 36\)。

2. 短除法（常用法及其局限性）
短除法本质上也是质因数分解，只是把提取公因数的过程排成了竖式。它对付较小的数非常直观。
例如求 \(12\) 和 \(28\)：先除以公因数 \(2\)，得到 \(6\) 和 \(14\)；再除以公因数 \(2\)，得到 \(3\) 和 \(7\)。此时 \(3\) 和 \(7\) 互质，停止。
左侧除数乘积 \(2 \times 2 = 4\) 即为 GCD；所有数相乘 \(2 \times 2 \times 3 \times 7 = 84\) 即为 LCM。

短除法的巨大弊端：当你遇到两个比较大的数（比如 \(3251\) 和 \(723\)），你很难一眼看出它们有什么公共质因数。此时硬做短除法，无异于大海捞针。这正是我们要引入“辗转相除法”的原因。

3. 辗转相除法（欧几里得算法，大数杀手）
这是求最大公约数最强大、最优雅的方法。核心原理：\(\gcd(a, b) = \gcd(b, a \bmod b)\)。
以 \(28\) 和 \(15\) 为例：\(28 \div 15 = 1 \dots 13\)；\(15 \div 13 = 1 \dots 2\)；\(13 \div 2 = 6 \dots 1\)；\(2 \div 1 = 2 \dots 0\)。
当余数变为 \(0\) 时，最后的除数 \(1\) 就是它们的最大公约数。

二、数论核心恒等式与数论函数

1. 黄金恒等式
对于任意两个正整数 \(a, b\)，它们的乘积等于它们的最大公约数与最小公倍数的乘积：

\(a \times b = \gcd(a, b) \times \text{lcm}(a, b)\)

实战意义：求 LCM 的最佳算法，不是硬算，而是先求 GCD，再算 \(\text{lcm}(a, b) = \frac{a \times b}{\gcd(a, b)}\)。

2. 约数个数定理
若正整数 \(n\) 的质因数分解为 \(n = p_1^{a_1} p_2^{a_2} \dots p_k^{a_k}\)，则 \(n\) 的正约数个数为：

\(d(n) = (a_1 + 1)(a_2 + 1) \dots (a_k + 1)\)

原理：在构造约数时，质因数 \(p_1\) 可以选 \(0\) 到 \(a_1\) 个，共 \(a_1 + 1\) 种选法，依此类推使用乘法原理。

3. 约数和定理
同样基于 \(n = p_1^{a_1} p_2^{a_2} \dots p_k^{a_k}\)，\(n\) 的所有正约数之和为：

\(\sigma(n) = \frac{p_1^{a_1+1} - 1}{p_1 - 1} \times \frac{p_2^{a_2+1} - 1}{p_2 - 1} \times \dots\)

原理：将 \((1 + p_1 + p_1^2 + \dots + p_1^{a_1}) \times \dots\) 展开，其每一项恰好都是一个不同的约数。

  2. 求 \(84\) 和 \(126\) 的最大公约数与最小公倍数（用两种方法：质因数分解与辗转相除）。
    点击查看答案
    \(84 = 2^2 \times 3 \times 7\)，\(126 = 2 \times 3^2 \times 7\)。
    质因数法：\(\gcd = 2^1 \times 3^1 \times 7^1 = 42\)；\(\text{lcm} = 2^2 \times 3^2 \times 7 = 252\)。
    辗转相除：\(126 \div 84 = 1 \dots 42\)，\(84 \div 42 = 2 \dots 0\)，\(\gcd = 42\)。LCM \(= 84 \times 126 \div 42 = 252\)。
  3. 求 \(360\) 的正约数个数及所有正约数之和。
    点击查看答案
    \(360 = 2^3 \times 3^2 \times 5^1\)。
    约数个数：\(d(360) = (3+1)(2+1)(1+1) = 4 \times 3 \times 2 = 24\) 个。
    约数和：\(\sigma(360) = \frac{2^4-1}{2-1} \times \frac{3^3-1}{3-1} \times \frac{5^2-1}{5-1} = 15 \times 13 \times 6 = 1170\)。
  4. 已知两个正整数的积为 \(576\)，它们的最大公约数为 \(8\)，求这两个数。
    点击查看答案
    \(\text{lcm} = 576 \div 8 = 72\)。
    设两数为 \(8x, 8y\)，且 \(\gcd(x,y)=1\)。则 \(8x \cdot 8y = 576 \Rightarrow xy = 9\)。
    互素的组合有 \((1, 9)\) 和 \((3, 3)\)（但 \(3,3\) 不互素，舍去）。
    所以两数为 \(8 \times 1 = 8\) 和 \(8 \times 9 = 72\)。
  5. 证明：对于任意正整数 \(a, b\)，\(a \times b = \gcd(a,b) \times \text{lcm}(a,b)\)。
    点击查看答案
    设 \(a = p_1^{\alpha_1} \dots p_k^{\alpha_k}\)，\(b = p_1^{\beta_1} \dots p_k^{\beta_k}\)。
    则 \(\gcd(a,b) = \prod p_i^{\min(\alpha_i, \beta_i)}\)，\(\text{lcm}(a,b) = \prod p_i^{\max(\alpha_i, \beta_i)}\)。
    两者的乘积为 \(\prod p_i^{\min(\alpha_i, \beta_i) + \max(\alpha_i, \beta_i)}\)。
    因为对任意实数 \(x, y\)，都有 \(\min(x,y) + \max(x,y) = x + y\)。
    所以 \(\min(\alpha_i, \beta_i) + \max(\alpha_i, \beta_i) = \alpha_i + \beta_i\)。
    因此乘积等于 \(\prod p_i^{\alpha_i + \beta_i} = (\prod p_i^{\alpha_i}) \times (\prod p_i^{\beta_i}) = a \times b\)。证毕。
  6. 证明：如果 \(a \mid c\)，\(b \mid c\) 且 \(\gcd(a, b) = 1\)，那么 \(ab \mid c\)。
    点击查看答案
    因为 \(\gcd(a,b)=1\)，所以 \(\text{lcm}(a,b) = a \times b\)。
    又因为 \(a \mid c\) 且 \(b \mid c\)，说明 \(c\) 是 \(a\) 和 \(b\) 的公倍数。
    而 \(\text{lcm}(a,b)\) 是所有公倍数中最小的正数，所以必有 \(\text{lcm}(a,b) \mid c\)。
    即 \(ab \mid c\)。证毕。
  7. 求 \(12\)、\(18\)、\(30\) 三个数的最大公约数和最小公倍数。
    点击查看答案
    \(12 = 2^2 \times 3\)，\(18 = 2 \times 3^2\)，\(30 = 2 \times 3 \times 5\)。
    GCD 取所有质因数的最小指数（注意 \(5\) 在12和18中没有，指数算0，所以 \(5\) 不取）：\(2^1 \times 3^1 = 6\)。
    LCM 取所有质因数的最大指数：\(2^2 \times 3^2 \times 5^1 = 180\)。
2. 剩余类与剩余系
一、引入：从连续整数的乘积说起

我们可以发现 \(10 \times 11 \times 12 \times 13\) 模 \(4\) 余 \(0\)，甚至任意连续的 \(4\) 个整数的乘积都模 \(4\) 余 \(0\)，你很容易知道为什么（因为必然包含了 \(4\) 的倍数）。
如果任意连续 \(4\) 个数连乘模 \(5\)，我们能一定得到唯一的答案吗？未必。但如果我们说首数模 \(5\) 余 \(1\)，那么答案是不是就唯一确定了？
这里我们似乎受到了某种启发，借此我们来系统地补充一下剩余系的具体分类。对于正整数 \(m\)：

二、三种常见的剩余系
  • 最小非负完全剩余系： \(0, 1, 2, \dots, m-1\)
  • 最小正完全剩余系： \(1, 2, \dots, m-1, m\)
  • 最小正简化剩余系（或称为缩系）： 从所有与 \(m\) 互素的剩余类中各取一个最小正代表元组成的集合。
    例如 \(12\)： 与其互素的最小的正整数分别为 \(1, 5, 7, 11\)，因此这便是 \(12\) 的最小正简化剩余系。这个概念在欧拉定理的证明中会起到关键作用。
    如果对于素数 \(p\)： 则其最小正简化剩余系即 \(1, 2, \dots, p-1\)。（因为除了 \(p\) 自己，其他都与其互素）。
🔍 知识补充：剩余类、剩余系及其核心性质

1. 剩余类：同余的“大抽屉”
在正式讲“剩余系”之前，我们要先理清“剩余类”的概念。
剩余类定义：把所有整数按照除以 \(m\) 的余数进行分类，余数相同的所有整数构成一个集合，这个集合就称为模 \(m\) 的一个剩余类（或同余类）。

你可以把它想象成 \(m\) 个“大抽屉”。比如模 \(4\)（即除以 \(4\)），一共有 \(4\) 个抽屉：

  • 余数为 \(0\) 的抽屉：\(\{ \dots, -8, -4, 0, 4, 8, 12, \dots \}\) （记作 \([0]\) 或 \(\overline{0}\)）
  • 余数为 \(1\) 的抽屉：\(\{ \dots, -7, -3, 1, 5, 9, 13, \dots \}\) （记作 \([1]\) 或 \(\overline{1}\)）
  • 余数为 \(2\) 的抽屉：\(\{ \dots, -6, -2, 2, 6, 10, 14, \dots \}\) （记作 \([2]\) 或 \(\overline{2}\)）
  • 余数为 \(3\) 的抽屉：\(\{ \dots, -5, -1, 3, 7, 11, 15, \dots \}\) （记作 \([3]\) 或 \(\overline{3}\)）
注意：一个“剩余类”里通常包含无穷多个数。

2. 剩余系：从抽屉里挑“代表”
现在，如果我们从上面模 \(4\) 的每一个“抽屉”（剩余类）里，各挑出一个数，组成一个新的集合，这个集合就叫作模 \(4\) 的一个完全剩余系。
比如，我们规定每次挑最小的正整数，就得到了 \(\{1, 2, 3, 4\}\)，这就是“最小正完全剩余系”。如果我们挑最小的非负整数，就得到了 \(\{0, 1, 2, 3\}\)。

3. 核心性质与严谨定义
完全剩余系：从模 \(m\) 的每个剩余类中各取一个数组成的集合。其元素个数恰好为 \(m\)。
核心性质：若 \(x\) 遍历模 \(m\) 的完全剩余系，且 \(\gcd(a, m) = 1\)（\(a, m\) 互素），那么 \(ax + b\) 也遍历模 \(m\) 的完全剩余系。
比如：\(m=5\)，完全剩余系取 \(0, 1, 2, 3, 4\)。令 \(a=2, b=1\)，则 \(2x+1\) 的值为 \(1, 3, 5, 7, 9\)。它们模 \(5\) 的余数分别为 \(1, 3, 0, 2, 4\)，恰好重新排布了 \(0, 1, 2, 3, 4\)。

简化剩余系（缩系）：从与 \(m\) 互素的每个剩余类中各取一个数组成的集合。
其元素个数恰好等于欧拉函数 \(\varphi(m)\)（即小于等于 \(m\) 且与 \(m\) 互素的正整数个数）。
核心性质：若 \(x\) 遍历模 \(m\) 的缩系，且 \(\gcd(a, m) = 1\)，那么 \(ax\) 也遍历模 \(m\) 的缩系。（这是证明欧拉定理 \(a^{\varphi(m)} \equiv 1 \pmod m\) 的核心步骤）。

2. 欧拉函数 \(\varphi(n)\) 的登场

小于 \(n\) 且与 \(n\) 互素的数的个数，记为欧拉函数 \(\varphi(n)\)。
例如 \(n = 10\)，互素的正整数为 \(1, 3, 7, 9\)，所以 \(\varphi(10) = 4\)。
你会发现，正是口诀表中的第 1、3、7、9 行（这些行首恰好是互素的数），它们的个位数遍历了所有的互素剩余类！

3. 举例验证与核心推导

如 \(n=10\)，互素的正整数为 \(a_1=1, a_2=3, a_3=7, a_4=9\)。
令 \(x=13\)，显然 \(x\) 与 \(10\) 互素。我们有：\(a_1x=13, a_2x=39, a_3x=91, a_4x=117\)。
注意到 \((a_1, a_2, a_3, a_4)\) 与 \((a_1x, a_2x, a_3x, a_4x)\) 模 \(10\) 后的余数是同一个类（都是 \(1,3,7,9\) 的排列）。

因此，将它们全部乘起来，同余式成立：

\((a_1x)(a_2x)(a_3x)(a_4x) \equiv a_1a_2a_3a_4 \pmod{10}\)

即：

\(a_1a_2a_3a_4 x^4 \equiv a_1a_2a_3a_4 \pmod{10}\)

移项提公因式：

\(a_1a_2a_3a_4(x^4 - 1) \equiv 0 \pmod{10}\)

由于 \(a_1a_2a_3a_4\) 与 \(10\) 互素，所以可以将它约去，得到：

\(x^4 \equiv 1 \pmod{10}\)

验证：\(13^4 = 28561\)，其个位数确实是 \(1\)。

这便是欧拉定理 \(x^{\varphi(n)} \equiv 1 \pmod n\)（当 \(\gcd(x,n)=1\) 时）的直观体现。而结合前文，当模数 \(n\) 是素数 \(p\) 时，\(\varphi(p) = p-1\)，这就得到了著名的费马小定理 \(x^{p-1} \equiv 1 \pmod p\)。

3. 模逆元
一、定义与存在条件

模逆元定义：对于整数 \(a\) 和模数 \(m\)，若存在整数 \(b\) 使得 \(ab \equiv 1 \pmod m\)，则称 \(b\) 为 \(a\) 在模 \(m\) 意义下的逆元（记作 \(a^{-1}\)）。

上述定义等价于：\(ab - 1 = mx \iff ab + m(-x) = 1\)。由此，根据裴蜀定理，可见逆元存在的充要条件是：

\(\gcd(a, m) = 1\)
并且此时，逆元 \(b\) 在模 \(m\) 意义下是唯一的。

二、具体例子与规律感悟

比如模 \(5\) 情况下：\(3 \times 2 \equiv 1\)，所以 \(2,3\) 互为逆元。而 \(1\) 和 \(4\) 的逆元是它们自己（\(1 \times 1 = 1\), \(4 \times 4 = 16 \equiv 1\)）。

对于素数 \(p\)，其最小正简化剩余系（缩系）中，\(1\) 和 \(p-1\) 与自己互为逆元，其余 \(p-3\) 个数则成对互为逆元。中间数 \(\frac{p+1}{2}\) 必与 \(2\) 互为逆元（因为 \(2 \times \frac{p+1}{2} = p+1 \equiv 1 \pmod p\)）。

对于合数，比如模 \(12\)，最小非负完全剩余系为 \(\{0, 1, 2, \dots, 11\}\)。其中 \(1, 5, 7, 11\) 这 \(4\) 个数与 \(12\) 互素，因此存在逆元；其余数不存在逆元。如下表：

（备注：∅ 代表不存在逆元。可以发现 \(1, 5, 7, 11\) 恰好就是模 \(12\) 的最小正简化剩余系）。

三、求模逆元的方法（以 \(4x \equiv 1 \pmod{13}\) 为例）

求解同余方程 \(4x \equiv 1 \pmod{13}\)，相当于求不定方程 \(4x + 13y = 1\) 的整数解。除了简单的尝试法（因为 \(4 \times 10 = 40 = 3 \times 13 + 1\)，所以 \(x=10\)），我们还可以用连分数/渐近分数来系统地求解。

提取参数：\(a = 13, b = 4\)。将 \(\frac{13}{4}\) 写成连分数：\(\frac{13}{4} = 3 + \frac{1}{4} = [3, 4]\)。构建渐近分数表：

\(i\)\(-1\)\(0\)\(1\)\(2\)
\(a_i\)\(3\)\(4\)
\(p_i\)\(0\)\(1\)\(3\)\(13\)
\(q_i\)\(1\)\(0\)\(1\)\(4\)
\(\Delta\)\(-1\)\(1\)

注：\(\Delta_i = p_i q_{i-1} - q_i p_{i-1}\)。当 \(\Delta = \pm 1\) 时即得到特解。

由此可得方程的特解为：\(\begin{cases} x_0 = -3 \\ y_0 = 1 \end{cases}\)（因为 \(13 \times 1 - 4 \times 3 = 1\)）。

通解为：\(\begin{cases} x = -3 + 13t \\ y = 1 - 4t \end{cases}, t \in \mathbb{Z}\)。

所以，\(x \equiv -3 \equiv 10 \pmod{13}\)，即 \(4\) 在模 \(13\) 下的逆元是 \(10\)。

    \(11 = 4 \times 2 + 3\)

    回代得：\(1 = 4 - 3 = 4 - (11 - 4 \times 2) = 3 \times 4 - 11 = 3 \times (15 - 11) - 11 = 3 \times 15 - 4 \times 11 = 3 \times 15 - 4 \times (26 - 15) = 7 \times 15 - 4 \times 26\)。
    所以 \(15 \times 7 \equiv 1 \pmod{26}\)，逆元为 \(7\)。
4. 良序原理
一、概念引入

良序原理是整数集（特别是自然数集）的一个极其基础且重要的性质。它指出：
任何一个非空的自然数集合，必定包含一个最小的元素。

这看起来是一句废话（“这不显然吗？”），但在数论的证明中，它却是证明存在性和进行无限递降（反证）的绝佳利器。很多结论一看就明白，但是证明起来无从下手时，我们可以构造一个集合，然后说“设 \(n\) 是这个集合中最小的正整数”，后面的逻辑往往就豁然开朗了。

二、实战演示：裴蜀定理的“最小正整数”证明

在数论中，良序原理最经典的应用之一是证明裴蜀定理（Bézout's Identity）。

【命题变更】：两个不全为零的整数 \(a, b\) 的最大公约数，是 \(a, b\) 的线性组合中最小的正整数。

证明：
设集合 \(S = \{ma + nb \mid m, n \in \mathbb{Z}, \text{且 } ma+nb > 0\}\)。
由于 \(a, b\) 不全为零，无论 \(a\) 的正负，我们总可以调整 \(m, n\) 的符号使得 \(ma + nb\) 为正数，因此集合 \(S\) 不是空集。
由良序原理，非空正整数集 \(S\) 中必定存在一个最小的元素。我们令这个最小的正整数为 \(d\)，则存在整数 \(m_0, n_0\) 使得：
\(d = m_0 a + n_0 b\)
接下来我们证明 \(d\) 就是 \(a, b\) 的最大公约数 \(\gcd(a,b)\)。
根据带余除法，将 \(a\) 除以 \(d\)，存在整数 \(q, r\) 使得：
\(a = dq + r, \quad 0 \le r < d\)
将 \(d\) 的表达式代入余数 \(r\) 中，得到：
\(r = a - dq = a - q(m_0 a + n_0 b)\)
\(r = a - q m_0 a - q n_0 b\)
\(r = (1 - q m_0)a + (-q n_0)b\)
这说明 \(r\) 也是 \(a\) 和 \(b\) 的线性组合。
因为 \(0 \le r < d\)，如果 \(r > 0\)，那么 \(r\) 就是集合 \(S\) 中的一个正整数，并且比我们假设的最小正整数 \(d\) 还要小！
这产生了矛盾。因此，唯一的可能就是 \(r = 0\)。既然 \(r=0\)，说明 \(a = dq\)，即 \(d \mid a\)。
同理，将 \(b\) 除以 \(d\)，也能得出 \(d \mid b\)。所以 \(d\) 是 \(a, b\) 的公因数。

最后证明 \(d\) 是“最大”的：
设 \(c\) 是 \(a, b\) 的任意一个公因数，即 \(c \mid a\) 且 \(c \mid b\)。
因为 \(d = m_0 a + n_0 b\)，由整除性质可知 \(c\) 必定整除 \(d\)，即 \(c \mid d\)。
由于 \(c, d\) 都是正整数，且 \(c \mid d\)，必然有 \(c \le d\)。
故 \(d\) 是所有公因数中最大的，即 \(d = \gcd(a,b)\)。
三、经典例题
  1. 例题1：利用良序原理证明 \(\sqrt{2}\) 是无理数。
    点击查看证明过程

    假设 \(\sqrt{2}\) 是有理数，则必定存在正整数 \(p, q\)，使得 \(\sqrt{2} = \frac{p}{q}\)。

    1. 构造集合并应用良序原理

    因为 \(q\sqrt{2} = p\) 是整数，所以使得 \(n\sqrt{2}\) 为整数的正整数 \(n\) 必定存在。设集合 \(S = \{n \in \mathbb{Z}^+ \mid n\sqrt{2} \text{ 是整数}\}\)，则 \(S\) 是非空的正整数集合。
    根据良序原理，\(S\) 中必定存在一个最小的元素，我们将其记为 \(n\)。
    此时，令 \(m = n\sqrt{2}\)，因为 \(n \in S\)，所以 \(m\) 是一个正整数。

    2. 利用不等式缩小范围

    因为 \(1 < \sqrt{2} < 2\)，两边同乘正整数 \(n\)，得到：
    \(n < n\sqrt{2} < 2n \implies n < m < 2n\)
    由此可知，\(0 < m - n < n\)。

    3. 构造更小的矛盾元素

    我们构造一个新的正整数 \(n' = m - n\)。
    显然 \(n' > 0\) 且 \(n' < n\)。接下来我们计算 \(n'\sqrt{2}\)：
    \(n'\sqrt{2} = (m - n)\sqrt{2} = m\sqrt{2} - n\sqrt{2}\)
    因为 \(m = n\sqrt{2}\)，代入上式：
    \(n'\sqrt{2} = (n\sqrt{2})\sqrt{2} - m = 2n - m\)
    因为 \(2n\) 和 \(m\) 都是整数，所以 \(2n - m\) 必定是整数。即 \(n'\sqrt{2}\) 是整数。

    4. 得出矛盾

    这意味着 \(n'\) 也是集合 \(S\) 中的一个元素，但 \(n' < n\)。这与我们前面规定的 \(n\) 是 \(S\) 中的最小元素相矛盾！

    结论：假设不成立，故 \(\sqrt{2}\) 必定是无理数。证毕。

  2. 例题2：证明带余除法定理（存在性）。
    点击查看证明过程
    对于任意整数 \(a\) 和正整数 \(b\)，构造集合 \(S = \{a - bk \mid k \in \mathbb{Z}, \text{且 } a - bk \ge 0\}\)。
    这个集合不是空集（当 \(k\) 取足够小的负数时）。
    由良序原理，集合 \(S\) 中存在一个最小的非负元素，设为 \(r\)。则存在整数 \(q\)，使得 \(r = a - bq\)，即 \(a = bq + r\)。
    假设 \(r \ge b\)，那么 \(r - b \ge 0\)。\(r - b = a - b(q+1)\)，这说明 \(r-b\) 也属于集合 \(S\)。
    但是 \(r - b < r\)，这与 \(r\) 是集合 \(S\) 中的“最小元素”相矛盾！因此必须有 \(r < b\)。
  3. 例题3：费马大定理的 \(n=4\) 情形（无限递降法）。
    证明方程 \(x^4 + y^4 = z^2\) 没有正整数解。
    点击查看证明思路
    假设存在解，根据良序原理，在所有解中取 \(z\) 最小 的那一组 \((x_0, y_0, z_0)\)。
    利用勾股数公式和代数变形，可以推导出一组新的解 \((x_1, y_1, z_1)\)，且满足 \(z_1 < z_0\)。
    这与“\(z_0\) 是最小的”产生矛盾，故原方程必定无解。
  4. 例题4：凑邮资问题（经典组合应用）。
    有面值为 3 分和 5 分的邮票（无限多），证明：对于任意大于 7 的整数 \(N\)，都可以刚好凑出 \(N\) 分的邮资。
    点击查看证明思路
    采用反证法。假设存在凑不出的数，由良序原理，在所有凑不出的数中，必定存在一个最小的数，设为 \(M\)。
    既然 \(M > 7\)，那么 \(M-3 > 4\)。因为 \(M\) 是最小的“凑不出”的数，所以 \(M-3\) 必定能凑出。
    在 \(M-3\) 的邮资基础上，我们只要再加一张 3 分邮票，就能凑出 \(M\)，这与假设矛盾！
5. 欧拉函数 \(\varphi(n)\)
一、回顾与定义

在【剩余系】的拓展视角中，我们观察了九九乘法表模 \(10\) 的情况。发现第 1、3、7、9 行（即与 10 互素的数）的个位数，恰好遍历了所有的互素剩余类。这就引出了一个核心概念：

欧拉函数定义：对于正整数 \(n\)，\(\varphi(n)\) 表示小于等于 \(n\) 且与 \(n\) 互素的正整数的个数。它衡量的是模 \(n\) 的最小正简化剩余系（缩系）的大小。

例如：
\(\varphi(5) = 4\)，因为 \(1, 2, 3, 4\) 都与 5 互素。
\(\varphi(10) = 4\)，因为 \(1, 3, 7, 9\) 与 10 互素。
\(\varphi(12) = 4\)，因为 \(1, 5, 7, 11\) 与 12 互素。

二、探索：\(\varphi(n)\) 的计算公式

我们以 \(12\) 为例来推导。\(12 = 2^2 \times 3\)。在 \(1\) 到 \(12\) 中：
能被 \(2\) 整除的数有：\(12 / 2 = 6\) 个。
能被 \(3\) 整除的数有：\(12 / 3 = 4\) 个。
如果直接写 \(12 - \frac{12}{2} - \frac{12}{3} = 2\)，这显然是错的（因为实际有 4 个）。错在哪里了呢？
错误在于“重复减去了”！ 能被 \(2\) 且能被 \(3\) 整除的数（即能被 \(6\) 整除的数，如 \(6, 12\)）被减了两次，需要加回来一次。
所以正确的个数是：\(12 - \frac{12}{2} - \frac{12}{3} + \frac{12}{2 \times 3} = 12 - 6 - 4 + 2 = 4\)。

这实质上就是容斥原理。把这一思想推广到含有多个质因数的 \(n\) 上。假设 \(n = p_1^{k_1} p_2^{k_2} \dots p_m^{k_m}\)，不互素的数占比就是从各个 \(p_i\) 的倍数中扣除并加还，最终合并同类项后，可以得到极为优美的连乘公式：

\(\varphi(n) = n \prod_{i=1}^m \left(1 - \frac{1}{p_i}\right)\)

其中 \(p_1, p_2, \dots, p_m\) 是 \(n\) 的所有不同的质因数。

实战一下：
对于 \(n = 12 = 2^2 \times 3\)，质因数是 \(2, 3\)。
\(\varphi(12) = 12 \times \left(1 - \frac{1}{2}\right) \times \left(1 - \frac{1}{3}\right) = 12 \times \frac{1}{2} \times \frac{2}{3} = 4\)。
对于 \(n = 100 = 2^2 \times 5^2\)，质因数是 \(2, 5\)。
\(\varphi(100) = 100 \times \left(1 - \frac{1}{2}\right) \times \left(1 - \frac{1}{5}\right) = 100 \times \frac{1}{2} \times \frac{4}{5} = 40\)。

三、实战习题
  1. 求 \(\varphi(36)\) 的值。
    点击查看答案
    将 \(36\) 分解质因数：\(36 = 2^2 \times 3^2\)，质因数为 \(2, 3\)。
    \(\varphi(36) = 36 \times \left(1 - \frac{1}{2}\right) \times \left(1 - \frac{1}{3}\right) = 36 \times \frac{1}{2} \times \frac{2}{3} = 12\)。
  2. 如果 \(p\) 是一个素数，求 \(\varphi(p^k)\) 的值（\(k\) 为正整数）。
    点击查看答案
    因为 \(p\) 是素数，所以 \(p^k\) 唯一的质因数就是 \(p\)。
    \(\varphi(p^k) = p^k \times \left(1 - \frac{1}{p}\right) = p^k - p^{k-1} = p^{k-1}(p - 1)\)。
    （注：在 \(1\) 到 \(p^k\) 中，只有 \(p\) 的倍数 \(1p, 2p, \dots, p^{k-1}p\) 一共 \(p^{k-1}\) 个不与 \(p^k\) 互素，所以 \(p^k - p^{k-1}\) 就是互素的个数）。
  3. 求 \(\varphi(100)\)，并验证 \(\varphi(100) = \varphi(4) \times \varphi(25)\)。
    点击查看答案
    \(100 = 4 \times 25\)，且 \(4\) 和 \(25\) 互素。
    \(\varphi(100) = 100 \times \left(1 - \frac{1}{2}\right) \times \left(1 - \frac{1}{5}\right) = 40\)。
    \(\varphi(4) = 2\)，\(\varphi(25) = 25 \times \left(1 - \frac{1}{5}\right) = 20\)。
    \(2 \times 20 = 40\)。这里验证了欧拉函数的一个重要性质：若 \(\gcd(m,n)=1\)，则 \(\varphi(mn) = \varphi(m)\varphi(n)\)（积性函数）。
